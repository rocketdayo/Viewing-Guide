# 2026清教学園高校文化祭 オンライン鑑賞ガイド

清教学園高校文化祭の公式オンライン鑑賞ガイド・ウェブアプリケーションです。ご挨拶、生徒スケジュール、各種企画詳細、リアルタイム混雑状況モニター、校内マップ、お知らせ配信機能を備えています。

## 🌟 主な機能

- **ご挨拶・案内**: 文化祭のテーマや来場者へのご案内
- **企画一覧・詳細**: 各クラス・団体の展示やパフォーマンス情報
- **生徒スケジュール**: タイムスケジュールおよび進行状況の確認
- **リアルタイム混雑モニター**: 校内各エリア・展示の混雑状況のリアルタイム確認
- **校内マップ**: 会場案内および施設マップ
- **お知らせ配信**: 文化祭実行委員会からの最新案内・連絡事項

## 🚀 開発・ビルド方法

### ローカル実行
```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

### ビルド
```bash
# 本番用ビルド（フルスタック）
npm run build

# GitHub Pages用静的ビルド
npm run build:pages
```

## 🌐 GitHub Pagesへの自動デプロイ

本リポジトリは GitHub Actions (`.github/workflows/deploy.yml`) による自動デプロイが設定されています。
`main` または `master` ブランチにプッシュすると、自動的にビルドされて GitHub Pages に公開されます。

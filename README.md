# 2026 清教学園高校文化祭 オンライン鑑賞ガイド

清教学園高等学校文化祭へお越しのみなさま、およびオンラインでご参加いただくみなさまのための公式鑑賞ガイドウェブサイトです。

## 📖 閲覧・ご使用方法

本ガイドはスマートフォンやパソコンのブラウザから直接ご利用いただけます。

### 1. 企画を探す・巡る
- **ホーム**: 文化祭の全体テーマやご案内、最新のお知らせを確認できます。
- **企画一覧**: 学年やフロア、キーワードから興味のあるクラス展示やパフォーマンスを探すことができます。
- **お気に入り（ブックマーク）**: 観に行きたい企画の「☆ お気に入り」ボタンを押すと、自分だけの巡回リストを作成できます。

### 2. 当日のスケジュール・進行状況
- **タイムスケジュール**: 舞台発表やイベントのタイムテーブルを確認できます。進行中のプログラムが一目でわかります。

### 3. 会場の混雑状況をチェック
- **リアルタイム混雑モニター**: 校内各エリアや人気の高い展示の現在の混雑状況（空いている・混雑中など）をリアルタイムで確認できます。混雑を避けたスムーズな移動にご活用ください。

### 4. 校内マップ・案内
- **校内マップ**: 各教室や階段、トイレ、受付の位置関係をマップで確認できます。

### 5. 便利機能
- **目次機能**: 画面上部の目次ボタンから目的のコンテンツへすぐに移動できます。
- **検索**: 企画名やキーワードで瞬時に目的の展示を検索できます。
